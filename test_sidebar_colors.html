✅ SESUDAH FIX - Inline Style Berfungsi

CSS class TIDAK memiliki property color, inline style berfungsi

WORKSPACE

Projects

Beranda & navigasi

Yang Terjadi:
• Inline style: style="color: #1e60be !important" (biru)
• CSS class: .header-text-after h3 { /* color removed */ }
• Hasil: Warna biru (#1e60be) sesuai inline style
BERHASIL - Warna sesuai setting
/* CSS Class TANPA property color */ .header-text-after h3 { font-size: 15px; font-weight: 800; margin: 0; /* color removed - using inline style */ } /* HTML dengan inline style */ <h3 style="color: #1e60be !important;">Projects</h3>

🎨 Referensi Warna

#1e60be - Text Color (biru, dari Workspace Settings)

#0066f5 - Muted Text Color (biru terang, dari Workspace Settings)

#94a3b8 - Default Gray (abu-abu, hardcoded di CSS class)

📚 Penjelasan Teknis

CSS Specificity

Urutan prioritas CSS (dari tertinggi ke terendah):

  1. Inline style dengan !important - Prioritas tertinggi
  2. ID selector dengan !important
  3. Class selector dengan !important
  4. Inline style tanpa !important
  5. ID selector
  6. Class selector
  7. Element selector

Mengapa Sebelumnya Tidak Berfungsi?

Walaupun inline style menggunakan !important, CSS class selector .header-text-before h3 tetap override karena:

  • CSS class didefinisikan SETELAH inline style di cascade order
  • Browser menerapkan CSS dalam urutan yang didefinisikan
  • Property color di CSS class "menimpa" inline style

Solusi

Dengan menghapus property color dari CSS class, tidak ada yang override inline style, sehingga warna dari Workspace Settings berfungsi.
